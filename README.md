## Hi, I'm Saurin 👋

Full-stack engineer at **METY Foundation** and **MyEdMaster LLC**, based in Lowell, MA.

### What I'm working on

- Building an **AI-assisted outreach platform** at METY Foundation: a React front end
  and a FastAPI back end that use an LLM to help draft personalized emails, which a
  person reviews before anything is sent.
- Running it on **Google Cloud Run** and **Netlify**, deployed by GitHub Actions with
  keyless sign-in, security scanning and locked dependencies.
